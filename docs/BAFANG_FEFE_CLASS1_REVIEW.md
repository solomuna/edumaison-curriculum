# Fe'fe' / Nufi - Bafang Class 1 - dossier de contribution et validation

## Statut

- Code de catalogue : `fmp`.
- Nom de catalogue : `Fe'fe' / Nufi`.
- Variante familiale pilote : `Bafang`.
- Pack : `fefe-fmp-bafang-class-1-foundations`.
- Version de travail : `0.1.0-draft`.
- Publication, activation et affectation : bloquees jusqu'a la fin de toutes les revues.

`Bafang` est conserve comme libelle familial de variante. Il ne devient pas un nouveau code de langue et ne doit pas etre applique aux autres familles sans leur choix explicite.

## Sources de cadrage

- Glottolog, fiche Fe'fe', code ISO 639-3 `fmp` et alias documentes : https://glottolog.org/resource/languoid/id/fefe1239
- Ressource alphabetique SIL Cameroun deja referencee par le catalogue EduMaison : https://www.silcam.org/resources/archives/5177

Ces ressources servent uniquement a identifier et cadrer la langue. Aucun mot, texte, dessin ou enregistrement externe ne doit etre copie dans EduMaison sans autorisation ou licence explicite.

## Modules envisages

1. Saluer, remercier et prendre conge.
2. Se presenter et nommer quelques proches.
3. Ecouter, montrer une image et repeter une forme courte.
4. Associer une image culturellement exacte a un mot valide.
5. Comprendre et employer de tres courtes phrases de classe.

Cette liste est une intention pedagogique. Elle ne valide aucun item linguistique et pourra etre corrigee par les relecteurs.

## Circuit de contribution

1. Un parent ou locuteur propose un item dans l'espace familial. La proposition reste privee et ne modifie aucun pack global.
2. La provenance, la variante, la traduction et le contexte d'usage sont obligatoires.
3. Un locuteur Bafang de confiance confirme que la forme est naturelle.
4. Une revue d'orthographe confirme les lettres, apostrophes et marques de ton.
5. Si un audio existe, un locuteur controle la prononciation, le ton, le bruit et le volume.
6. Une revue pedagogique confirme que l'item convient a Class 1 et que l'image ne donne pas une fausse reponse.
7. Seul un responsable de contenu peut integrer un item approuve au pack. Aucune soumission familiale n'est publiee automatiquement.

## Fiche obligatoire par item

| Champ | Valeur attendue |
| --- | --- |
| Identifiant de proposition | Identifiant interne sans nom d'enfant |
| Variante | `Bafang` ou libelle corrige par le relecteur |
| Forme Fe'fe' / Nufi | Orthographe exacte, tons compris |
| Traduction francaise | Sens dans ce contexte |
| Traduction anglaise | Sens dans ce contexte |
| Type | mot, expression ou phrase courte |
| Contexte | situation concrete d'emploi |
| Exemple naturel | valide par un locuteur |
| Source | contributeur, creation interne ou reference autorisee |
| Droits | autorisation et restrictions |
| Audio | locuteur adulte, variante, date et consentement |
| Revue linguistique | relecteur, date, decision et remarques |
| Revue pedagogique | relecteur, date, decision et remarques |

Ne jamais inscrire dans ce dossier le nom d'un enfant, une adresse, un telephone, une credentielle ou un autre renseignement prive.

## Revue obligatoire du pack

- [ ] Le libelle `Bafang` et sa zone d'usage sont confirmes par le locuteur.
- [ ] Le perimetre Class 1 est relie au programme scolaire utilise par EduMaison.
- [ ] L'alphabet, les apostrophes et les marques de ton sont confirmes.
- [ ] Chaque item est traduit dans les deux sens avec son contexte.
- [ ] Chaque phrase est jugee naturelle par un locuteur Bafang.
- [ ] Les images sont culturellement exactes et leurs droits sont documentes.
- [ ] Chaque audio dispose du consentement du locuteur et passe le controle qualite.
- [ ] Un second locuteur relit les items lorsque cela est possible.
- [ ] La revue pedagogique Class 1 est signee.
- [ ] Le nom des relecteurs adultes, les dates, la variante et la decision sont consignes dans l'outil de revue protege.

## Regle de publication

Le statut ne peut passer de `draft` a `verified` qu'apres la levee de tous les blocages. La version publiee doit etre distincte de `0.1.0-draft`, porter une date de revue, ne contenir que les items approuves et rester limitee a `fmp` et a la variante validee.
